# Images Directory

Place all your portfolio images in this folder.

## Required Images

### Hero Section
- `hero-photo.jpg` - Your professional photo for the hero section (recommended: 800x600px or larger)

### About Section
- `about-photo.jpg` - A photo for the about section (recommended: 600x400px or larger)

### Project Screenshots
- `crop-disease-ai.jpg` - Screenshot of Crop Disease Detection AI project
- `invoice-generator.jpg` - Screenshot of Invoice & Receipt Generator project
- `movie-booking.jpg` - Screenshot of Movie Ticket Booking System project
- `labops-toolkit.jpg` - Screenshot of LabOps Automation Toolkit project

### Gallery Images
- `gallery-lab-work.jpg` - Lab work photo
- `gallery-tech-event.jpg` - Tech event photo
- `gallery-milestone.jpg` - Personal milestone photo
- `gallery-project-shot.jpg` - Project screenshot
- `gallery-research.jpg` - Research work photo
- `gallery-workshop.jpg` - Workshop photo
- `gallery-campus-life.jpg` - Campus life photo
- `gallery-prototype.jpg` - Prototype photo

## Image Guidelines

- **Format**: JPG, PNG, or WebP
- **Size**: Keep file sizes reasonable (under 500KB per image for web performance)
- **Dimensions**: 
  - Hero photo: 800x600px or larger (aspect ratio ~4:3)
  - About photo: 600x400px or larger
  - Project screenshots: 1200x800px or larger (aspect ratio 3:2)
  - Gallery images: 800x600px or larger (will be cropped to square)

## How to Add Images

1. Copy your image files into this `assets/images/` folder
2. Name them exactly as listed above (case-sensitive)
3. The website will automatically display them
4. If an image is missing, a placeholder will show instead

## Tips

- Use image compression tools (like TinyPNG) to reduce file sizes
- Ensure images are well-lit and professional
- For project screenshots, capture the most impressive/representative view
- Gallery images can be rotated using the Prev/Next buttons on the website
